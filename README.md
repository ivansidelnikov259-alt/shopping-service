# Shopping Service - Сервис учета покупок и формирования списка покупок

## Назначение

Веб-приложение для учета личных покупок, планирования бюджета и создания списков покупок. Сервис помогает пользователям отслеживать свои расходы, анализировать покупательское поведение и эффективно планировать покупки перед походом в магазин.

## Целевая аудитория

- Люди, которые хотят контролировать свои расходы и вести семейный бюджет
- Семьи, планирующие совместные покупки и распределяющие бюджет
- Пользователи, которым нужно систематизировать процесс покупок
- Люди, стремящиеся к осознанному потреблению и оптимизации расходов

## Предметная область

Сервис предоставляет возможность вести учет совершенных покупок, создавать списки необходимых товаров, отслеживать расходы по категориям и магазинам. Пользователи могут планировать бюджет, анализировать свои траты и оптимизировать процесс совершения покупок. Приложение позволяет хранить историю покупок, группировать товары по категориям и формировать статистику расходов.

## Основные сущности

- **Пользователь** — аккаунт пользователя сервиса, владелец списков и покупок
- **Покупка** — запись о совершенной покупке с указанием товара, цены, даты и магазина
- **Магазин** — торговая точка, где совершаются покупки
- **Категория** — группа товаров по назначению (продукты, бытовая химия, одежда и т.д.)
- **Список** — планируемый набор покупок для похода в магазин
- **Товар** — конкретный товар с названием, ценой и принадлежностью к категории

## Основные функции

- Добавление и учет совершенных покупок с указанием цены, категории, магазина и даты
- Просмотр истории покупок с итоговой суммой расходов
- Анализ расходов по категориям для контроля бюджета
- Создание и редактирование списков покупок
- Отслеживание расходов по магазинам
- Формирование статистики и аналитики покупательского поведения
